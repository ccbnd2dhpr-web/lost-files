# L0ST F1LES

an album you explore like an old DVD menu. by ODYSSEY.

## download

**[get the latest version here](https://github.com/ccbnd2dhpr-web/lost-files/releases/latest)**: download the `L0ST-F1LES-Setup` file and open it. it installs itself and opens. that's it.

- windows only
- if windows says "Windows protected your PC", click **More info**, then **Run anyway**. it says that because the installer isn't signed, not because something's wrong.
- updates are automatic. when a new version is out, the app downloads it and installs it the next time you close it.
- your progress is saved on your computer, and updates and reinstalls keep it.

## uninstall

Settings → Apps → Installed apps → L0ST F1LES → Uninstall.
